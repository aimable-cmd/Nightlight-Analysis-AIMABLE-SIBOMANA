# Nightlight-Analysis-AIMABLE-SIBOMANA
Nightlight Analysis Environment

# Project Overview

This project analyzes nightlight intensity in Rwanda using satellite imagery and administrative boundaries. Zonal statistics are computed at the Admin 4 level to support socio-economic insights.

# Contents

notebooks/: Jupyter notebook with full analysis

data/ntl/rw-adm4-ntl-stats.csv: Final zonal statistics output

requirements.txt: Python dependencies

screenshot.png: Environment verification screenshot

⚠️ Large Raster File Not Included
